# 复合微通道分区冷却 · 月度报告

五个逻辑月的月度报告，按组长提纲的关键词组织。

## 大创修改核心要求

1. 月度报告统一命名为 `逻辑月N_主题.pdf`，对应源文件为同名 `.tex`。例如 `逻辑月1_基础建立.pdf` 和 `逻辑月1_基础建立.tex`。禁止添加 `_v1_1`、`_v2_0` 等版本后缀；修订更新同名文件，版本历史由 Git 管理。
2. 所有报告配图的生成代码、分析代码和辅助脚本统一放在 `reports/figs/src/`；相关输入数据、中间数据及复现说明也放在该目录。
3. `reports/figs/` 根目录只放报告使用的图片文件及 `src/` 子目录，不放代码、数据、说明文档或临时文件。备用图与中间图放在 `src/`，正式引用时再放入 `figs/`。
4. 重命名或移动文件时，同步更新报告引用、文档链接和脚本路径；提交前检查文件命名与目录归属，并按现有规范完成报告编译自检。

## 报告的写法

- **有素材的写实**——数据来自三人的实际仿真与文献工作
- **无素材的留空**——用标记标出，不编造：

| 标记 | 含义 |
|---|---|
| `【待确认N】` | 需组长明确的信息 |
| `【缺数据：……】` | 手上没有的数据 |
| `【待补：……】` | 工作尚未开展 |

## 编译

需要 XeLaTeX（中文）。每份报告跑两遍：

```bash
xelatex 逻辑月1_基础建立.tex
xelatex 逻辑月1_基础建立.tex
```

**Overleaf**：上传 `.tex` 与 `template/ydzjreport.cls` 到同一目录，
Menu 到 Compiler 选 **XeLaTeX**（默认是 pdfLaTeX，不改会报错）。

字体由 ctex 自动检测（Windows 用 SimSun，Overleaf 用 Fandol），
三人的 PDF 字形可能略有差异；若要求完全一致，在 `\documentclass` 加 `fontset=fandol`。

## 自检

```bash
python check.py
```

会检查括号平衡、交叉引用、图片文件，并编译验证。
**`Overfull` / `Missing character` / `Error` 三项必须都是 0。**
