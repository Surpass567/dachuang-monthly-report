# 版本 B · 长版（发群公告，说清来龙去脉）

```
【月度总结格式统一方案】

问题
我们仨用不同的 AI 工具（Workbody / Codex / 网页版）写月度总结，
只靠一句"写份总结"，排版必然五花八门，放一起一眼就能看出不是一套。

解法
做了一份共享的 LaTeX 文档类 ydzjreport.cls，版式全在里面。
大家只管填内容，格式自动统一——章节编号、表格换行、字体都不用操心。

为什么用 LaTeX 而不是 Word
排版完全可控，同一份文件在 Overleaf 和本地都能编译出一样的结果，
不会因为 Word 版本不同而跑版。

仓库
https://github.com/Surpass567/dachuang-monthly-report

打不开 GitHub 的（校园网有时抽风）：直接在群里说一声，我发 zip 给你。

上手三步
1. 打开仓库 → 绿色 Code → Download ZIP（不会 Git 就下 zip，效果一样）
2. 把 ydzjreport.cls + 你那个阶段的 .tex 传到 Overleaf，
   Menu → Compiler → 选 XeLaTeX（这步不能忘）
3. 改开头六项信息，然后按章节填

格式要求（硬性）
· 章节骨架别动，标题文字别改
· 不要手写章节编号
· 数字和单位之间加空格：2.8 mm
· 不要用 emoji 和圈号（✅❌⚠️★①②）——中文字体没这些字形，会变空白
· 表格用 tabularx + Y 列，不超过 6 列
· 特殊字符要转义：% → \%，& → \&，_ → \_

提交前自检
跑 python check.py（本地），或在 Overleaf 看 Raw Log，
Overfull / Missing character / Error 三项必须都是 0，否则别交。

两种阶段的区别（别写混）
· 阶段一 · 初步阅读
  主线是"学习过程"，必须有"导出与复现"环节（环境+步骤+结果）。
  只罗列文献不算完成。
· 阶段二 · 研究推进
  主线是"研究进展"，"与预期的差异"和"尚不能确定的"不能为空。
  全都符合预期 = 没有深入思考。

改版式
.cls 是唯一源，别各自改。要改先跟我说，我统一改完推上去，
然后所有人重新拉一次、重新编译一遍。

不会用 Git 的
完全不用学。直接找我要 zip，或者在群里说一声。
你只要保证用的是最新版模板，怎么编译都无所谓——版式一样，格式就统一了。
```

# 首次发布后，过几天追一条

```
提醒一下：用模板的时候注意两点，已经有人踩过：

1. Overleaf 的 Compiler 默认是 pdfLaTeX，必须手动改成 XeLaTeX，
   不改的话中文会编译失败。

2. 章节标题别自己加编号。写了"一、阅读范围"会和自动编号叠成
   "2 一、阅读范围"。

另外，"与预期的差异"这一节别写"符合预期"就完事。
哪怕结果真的符合预期，也要写清为什么符合；有偏差就分析主因。
这节空了会被打回。
```

# 发通知的几个建议

1. **短版发群里，长版发群公告**——群消息会被刷掉，公告不会
2. **重要的事发两遍**：刚建仓库时发一次，一周后再提醒一次
3. **别用"详见文档"打发人**——把最关键的 3 件事直接写在群里
4. **给不会 Git 的人留台阶**：明确说"不会就说一声，我发 zip"
   不要让人觉得必须先学 Git 才能参与
5. **报错让贴日志**，不要说"编译失败"就完事——有日志才能定位
