# 缺口与不明确项说明

整理人：张昊洋 日期：2026-10-15
配套文档：《研究主线整合方案（按组长关键词组织）》

**本文用途**：把整合方案里留空的地方**逐条说清楚**——
是什么、卡在谁那里、怎么补、补不了会有什么后果。

---

## 总览

| 类别 | 条目数 | 说明 |
|---|---|---|
| A. 需要组长明确的概念 | 4 | 关键词含义不明，不定就没法往下做 |
| B. 缺数据 | 5 | 数据不存在，需要补测或补算 |
| C. 未开始的工作 | 6 | 产出物还不存在 |
| D. 需要三人约定的接口 | 3 | 接口没定，会导致数据不可比 |

**其中 A 类必须由组长回答**（我们无法自行决定）；
B、C 类我们可以想办法补，但需要时间和条件；
D 类需要三个人当面确认。

## A. 需要组长明确的概念（4 条）

### A1 · "防身"是不是"防护"，具体指什么？

| 项目 | 内容 |
|---|---|
| **出处** | 月份 2 关键词：`小块（1. 形态 2. 防身 3. 扰流性到 翼型）` |
| **问题** | "防身"不是结构领域的常用词。疑为"**防护**"，但**防什么**不明确 |
| **三种可能理解** | ① 防**局部过热**（热点保护）；② 防**堵塞/结垢**（流道长期可靠性）；③ 防**结构失效**（强度、变形） |
| **现状** | **三人 6 份报告里这一项完全空白**，没人做过任何相关工作 |
| **为什么重要** | 它和"形态""扰流"并列，说明组长认为它是**同等重要的一类工作**，不是附带项 |
| **不问的后果** | 月份 2 少一类工作，且后面几个月没人补 |
| **建议问法** | "月份 2 的'防身'是不是'防护'？具体是防过热、防堵塞，还是防结构失效？" |

---

### A2 · 月份 3 的"形态 物理"具体指什么？

| 项目 | 内容 |
|---|---|
| **出处** | 月份 3 关键词：`形态 物理`（只有两个词） |
| **问题** | 两个词都太宽，无法判断工作量与产出物 |
| **我对"形态"的推测** | 把月份 2 的候选**收敛定型**（陈思文已提"聚焦单个扰流柱，逐一控制变量"，与此吻合） |
| **我对"物理"的推测** | 两条路：① **物性基础**（UDF 的延续与复算）② **物理场机理**（流场／温度场分析） |
| **现状** | 无法判断月份 3 到底要产出什么，因此**无法排期** |
| **为什么不自行决定** | 这两个词决定了月份 3 是"做仿真"还是"做分析"，工作量差别很大 |
| **建议问法** | "月份 3 的'形态'是指形态定型吗？'物理'是指物性（UDF），还是物理场机理分析？这两项是并行还是先后？" |

---

### A3 · 月份 1 的"复现 2~3 学长"具体指谁？

| 项目 | 内容 |
|---|---|
| **出处** | 月份 1 关键词：`复现 2~3 学长（结构 物理性质（UDF））思路` |
| **问题** | ① 是哪几位学长？② 复现**整篇论文**还是只复现**"结构 + UDF 设置"这两套**？ |
| **我们已做的** | 陈思文：Fluent 上手、肋片/坑道对比；冯旭东：复现 Ao 等三种流道 |
| **不确定的地方** | 我们复现的是**已发表的论文**（Ao、Yin、Seong），**不是"学长"**。两者是否等同？ |
| **为什么重要** | 如果组长指的是**某几位具体学长的未发表工作**，我们需要拿到他们的模型或数据；如果是已发表论文，那我们已经做了大半 |
| **建议问法** | "月份 1 要复现的 2~3 位学长是哪几位？是复现他们的论文，还是复现他们的结构模型和 UDF 设置？我们复现的 Ao 三种流道算不算？" |

---

### A4 · 指标口径统一到哪一套？

| 项目 | 内容 |
|---|---|
| **出处** | 月份 2 关键词：`1. 指标` |
| **问题** | 三人用的指标体系**互不相同**，且**两个 PEC 的基准不一样** |
| **具体差异** | 见下表 |
| **为什么是硬问题** | PEC、Nu 这类归一化指标**必须同一个基准**才能横向比较。基准不同，数值**不可比**，三个人的结论就拼不到一起 |
| **建议问法** | "指标统一到哪一套？PEC 的基准用直通道还是 NACA0015？是否要求三人用完全相同的指标表？" |

| 指标 | 陈思文 | 冯旭东 | 张昊洋 |
|---|---|---|---|
| 温度 | 最高温、底板平均温 | 最高温、体积平均温 | 加热面平均／最高／极差 |
| 换热 | h、Nu | Nu_avg | h、Nu |
| 阻力 | 压差（定性） | 压差、水力功率 | 压差、摩擦因子、泵功 |
| 综合 | PEC（基准 **NACA0015**） | PEC（基准 **直通道**） | 未用 PEC |
| 热阻 | 未用 | 峰值热阻 | 热阻 |

**附带的隐患**：特征长度怎么取、物性在哪个温度取值、面积平均还是体积平均——这三项三人也都不一样，且**都影响数值**。

## B. 缺数据（5 条）

说明：B 类数据**部分可以从现有成果中导出**，不一定需要新做仿真。每条形标注了获取难度。

### B1 · "流速 → 温度"关系（控制方向急需）最容易补

| 项目 | 内容 |
|---|---|
| **我要它做什么** | 我报告里的待辨识函数 g（流速／水温／热流 → 芯片温度）需要**稳态增益**才能标定 |
| **现有条件** | 冯旭东手上有**39 个有效工况**（温度 vs 热流密度），**已包含总流量字段** |
| **缺什么** | ① 每个工况的**流速**（或可由总流量＋截面积换算）；② 温度字段的**确切定义**（最高温／体积平均／加热面） |
| **获取难度** | **低** —— 大概率不需要新做仿真，只需把现有工况表补齐两个字段 |
| **谁来做** | 冯旭东 |

### B2 · 连接段阻力系数（月份 4 → 控制方向）

| 项目 | 内容 |
|---|---|
| **我要它做什么** | 函数 f（执行器 → 流速）里需要**管路阻抗**；连接段是小块之间最主要的阻力来源 |
| **现有条件** | 冯旭东已明确"设计小块连接处的过渡与分流通道"这一方向，但**尚未开始** |
| **缺什么** | 连接段的阻力系数或压降—流量关系 |
| **获取难度** | **中** —— 需要在月份 4 做连接段仿真时**顺带输出**，不需要额外工作 |
| **建议** | 在连接段设计的仿真里，直接把压降特性作为产出物之一 |

### B3 · 新 UDF 挂接后的物性校验结果

| 项目 | 内容 |
|---|---|
| **背景** | 冯旭东发现原水物性有误（298.15 K 下密度偏低 60.8%、比热偏低 10.5%、黏度偏低 26.7%），并**已编译新 UDF** |
| **缺什么** | 新 UDF **挂接后**的物性自检结果（源码里有 300 K 和 330 K 的自检输出，但未看到校验记录） |
| **为什么重要** | 月份 2 的所有结论（厚翼型有利、弯度有害）都建立在**旧物性**上。物性修正后**排序是否变化**，目前无人知道 |
| **获取难度** | **低** —— 挂接 UDF 并跑自检即可 |
| **谁来做** | 冯旭东 |

### B4 · 各支路流量分配与连接段压降

| 项目 | 内容 |
|---|---|
| **出处** | 月份 4 关键词：`优化` |
| **缺什么** | 整板分流后各支路的实际流量、连接段压降 |
| **为什么重要** | 冯旭东已指出：**并联时高阻力支路可能供液不足**。没有支路流量数据，就无法判断分流是否合理 |
| **获取难度** | **高** —— 需要先有网络拓扑与连接段模型 |
| **依赖** | 依赖 C4、C5 完成 |

### B5 · 控制实验所需的条件信息

| 项目 | 内容 |
|---|---|
| **我要它做什么** | 我报告里的控制实验方案（泵扫／阀扫／耦合验证，约 13 组）需要明确的实验条件 |
| **缺什么** | ① 泵的型号与流量范围 ② **水阀是否已加装**（目前确认是"未来加装"） ③ 有没有流量计 ④ 温度采样频率 ⑤ **小块之间是否独立供液** |
| **为什么重要** | 第 ⑤ 项直接决定控制架构：**独立供液 → 多回路控制；共用流路 → 单回路**。两种架构的算法完全不同 |
| **获取难度** | **低** —— 属于台架条件，问一下就知道 |

## C. 未开始的工作（6 条）

| 编号 | 工作 | 对应月份 | 依赖 | 后果 |
|---|---|---|---|---|
| C1 | **小块划分图** | 1 | 无 | 月份 1 的"小块→具体"没有可视化产出；后面所有"按小块设计"缺少统一参照 |
| C2 | **单柱基准模型** | 3 | 网格基准（已有） | 陈思文已指出"多柱干扰无法解耦"，没有单柱模型就无法剥离单参数影响 |
| C3 | **代表工况复算（新物性）** | 3 | B3 | 现有排序可能失效，但没人验证 |
| C4 | **网络拓扑与连接段设计** | 4 | C2 | 月份 5 的整板无从组装 |
| C5 | **支路流量分配方案** | 4 | C4 | 无法判断分区设计是否真的把流量分对了 |

**说明**：C 类不是"遗漏"，而是**本来就在未来月份**。列出来是为了看清**依赖顺序**——
比如 C6 卡在 C4/C5，而 C4 又卡在 C2，所以**单柱基准模型（C2）其实是最上游的关键路径**。

## D. 需要三人约定的接口（3 条）

### D1 · 陈思文的单柱模型是否沿用冯旭东的网格基准？

| 项目 | 内容 |
|---|---|
| **背景** | 冯旭东已完成四种流道的网格无关性检验，形成**约 150 万网格**的后续基准 |
| **问题** | 陈思文的单柱模型**是否也用这个基准**？ |
| **不约定的后果** | 两人的单柱数据**不可比**，而他们做的其实是同一件事的不同侧面 |
| **建议** | 陈思文的单柱模型直接沿用冯旭东的网格基准与边界条件口径 |

### D2 · 控制方向的数据交接格式

| 项目 | 内容 |
|---|---|
| **问题** | 我需要结构方向的"流速→温度"数据（见 B1），但**用什么格式交、包含哪些字段**没定 |
| **建议字段** | 工况编号、热流密度、总流量或流速、入口温度、最高温、平均温（注明平均方式）、压差、保存时刻 |
| **不约定的后果** | 数据拿到但字段对不上，还要返工 |

### D3 · "小块"的定义是否统一？

| 项目 | 内容 |
|---|---|
| **问题** | 三份报告里出现了三种说法，**不清楚是不是同一件事** |
| **三种说法** | 陈思文："芯片底部中央的**浮动热流密度区**"；冯旭东：**"低温区／变化区／高温区"**；我（控制）：需要知道**小块之间是否独立供液** |
| **为什么重要** | ① 若说法不同，月份 1 的"小块→具体"到底要具体化什么就说不清；② 独立供液与否决定控制架构（见 B5） |
| **建议** | 定一份小块定义，说明划分依据（按热流密度？按位置？）、数量、边界 |

## 优先级：先解决哪些

```
第一层（不定就停摆）
  A1 防身是什么      A2 月份3指什么
  A3 复现谁          A4 指标口径
        |
        v
第二层（能立刻补，成本低）
  B1 流速→温度（只需补字段）
  B3 新UDF物性校验（挂接即可）
  B5 控制实验条件（问一下）
        |
        v
第三层（需要约定）
  D1 单柱网格基准    D2 数据格式    D3 小块定义
        |
        v
第四层（按月份推进）
  C1 小块划分图 → C2 单柱基准 → C3 复算 → C4 网络 → C5 分流 → C6 整板
```

## 一句话总结

**A 类 4 条必须问组长**（概念不明，我们无权决定）；
**B1 最值得先补**（只差两个字段，却是控制方向的关键输入）；
**D3「小块定义」是最该先统一的**（它同时影响月份 1 的产出和控制的架构）。
