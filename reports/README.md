# 各人的月度报告放这里

## 命名规则

```
YYYY-MM_阶段N_姓名_方向.tex
YYYY-MM_阶段N_姓名_方向.pdf
```

例：

```
2026-10_阶段一_张三_导流柱结构设计.tex
2026-10_阶段一_张三_导流柱结构设计.pdf
2026-10_阶段二_李四_流量控制.tex
2026-10_阶段一_王五_热场预测.pdf
```

**规则说明**：

- 月份补零两位：`2026-09`，不是 `2026-9`
- 阶段用中文数字：`阶段一` / `阶段二`
- 方向用 2–6 个汉字，不用英文缩写

## 怎么写

1. 从 `../template/` 复制对应阶段的空白骨架到这里，改名
2. 编辑内容
3. 编译并自检（见下）
4. 提交

**`.cls` 不用复制到这里** —— 如果编译时提示找不到 `ydzjreport.cls`，把 `../template/ydzjreport.cls` 复制一份过来，或者干脆在 `template/` 目录里写，写完再移过来。

## 编译

**Overleaf**：`.cls` 和 `.tex` 必须同层。最省事的做法是把两个文件都传到项目根目录。

**本地**：

```bash
cd reports
xelatex 2026-10_阶段一_张三_导流柱结构设计.tex
xelatex 2026-10_阶段一_张三_导流柱结构设计.tex    # 跑两遍
```

## 提交前自检

```bash
cd ..
python check.py reports/2026-10_阶段一_张三_导流柱结构设计.tex
```

**必须看到 `[PASS] Overfull=0 Missing=0 Error=0`。**

三项有任何一个不为 0 就不要提交。修法见 [CONTRIBUTING.md](../CONTRIBUTING.md)。

## 图片放哪

如果报告里有图，放在：

```
reports/figs/<你的名字>/图1.png
```

引用时：

```latex
\includegraphics[width=0.85\textwidth]{figs/张三/图1.png}
```

**按人名分目录是为了避免重名冲突。**

## 交不交 PDF

**建议交 `.tex` + `.pdf` 两份**：

- `.pdf` —— 方便别人直接看
- `.tex` —— 万一后面要统一改格式（比如加公章栏），有源文件才能批量处理

**只交 PDF 也能接受**，但要知道这个风险。
