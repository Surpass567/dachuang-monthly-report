# 月度报告

五个逻辑月的报告，按组长提纲的关键词组织。

| 逻辑月 | 文件 | 页数 |
|---|---|---|
| 1 | `逻辑月1_基础建立.tex` / `.pdf` | 4 |
| 2 | `逻辑月2_指标与形态.tex` / `.pdf` | 6 |
| 3 | `逻辑月3_形态与物理.tex` / `.pdf` | 4 |
| 4 | `逻辑月4_连接成网络.tex` / `.pdf` | 4 |
| 5 | `逻辑月5_整板验证.tex` / `.pdf` | 4 |

## 命名

`逻辑月N_主题.tex` / `.pdf`——按**逻辑月**编号，不对应自然月；
月份边界待定，定后可在元信息表里补上自然月区间。

## 编译

在 `reports/` 目录下：

```bash
xelatex 逻辑月1_基础建立.tex
xelatex 逻辑月1_基础建立.tex
```

需要 `../template/ydzjreport.cls`。若编译报找不到该文件，
把 `template/ydzjreport.cls` 复制到本目录。

## 配图

`figs/` 下有 4 张图与生成脚本。重新生成：

```bash
cd figs
python PID仿真.py      # 先生成数据
python 生成配图.py      # 再画图
```

## 留空标记

报告里不明确、缺数据之处用标记标出，含义见各报告开头的「阅读说明」。
