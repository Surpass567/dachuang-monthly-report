# 报告提交版本

本目录提供五份月报和中期报告的无图表正文，以及与各正文一一对应的图表附件。上级目录的完整报告保留不变。

- `正文/`：提交使用的 PDF 与同名 LaTeX 源文件。正文中的图片、组图、普通表格、跨页长表已删除，原位置单独写明“图 X 请参见附件图 X。”或“表 X 请参见附件表 X。”；公式、章节、论述和参考文献保留。
- `图表附件/`：单独提交的 PDF 与同名 LaTeX 源文件。图表、表内数据、图题与表题取自完整报告，编号保持不变；组图的子图编号也保留，附件末尾保留原报告的参考文献。
- [图表对应清单](图表对应清单.json)：记录每份报告的全部图表编号和交叉引用标签。

## 复现与验证

在 `reports/` 执行 `python -X utf8 figs/src/build_submission_versions.py`，使用本机已配置的离线 Tectonic 编译。共享类仍使用仓库 `template/`，图像仍引用 `reports/figs/`，未复制公共模板和图片。构建日志、原稿编号数据、视觉检查中间图位于 `reports/figs/src/submission_build/`，不作为提交文件。

检查包括正文无图表环境、PDF 无嵌入图片、各条附件提示存在、图表及子图引用编号与原稿一致，以及 Overfull、Missing character、Error、未定义引用均为零。结果见[验证记录](../figs/src/submission_build/validation.json)。
