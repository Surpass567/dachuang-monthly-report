# NACA2416 网格异常排查（323 万与 461 万，t=0.2 s）

## 结论

1. 原先“304.3 K → 306.0 K”主要是单元算术平均的网格权重效应。全域体积加权温度为 305.779308 K 与 305.867350 K，仅差 0.088042 K；流体体积加权温度差 0.039089 K。后续平均温度应按相同区域的体积加权口径比较。
2. 两组均存在真实出口回流，回流面温度确实被固定为 305 K。但 461 万的回流质量流量比 323 万更小，现有结果不能支持“只有 461 万被出口污染”或“461 万回流更严重”。
3. 两组网格生成策略不同：边界层设置层数、最小表面尺寸与核心最大尺寸均不同。461 万不能简单解释为同一网格策略下的下一档均匀加密。它解析出了更强的局部内部逆向速度，但这并不自动意味着结果更准确。
4. 压降差 100.393755 Pa 仍然存在；Nu 差约 1.56%。两组末段温度、压降变化远小于组间差值，单纯延长到 0.2 s 已不能消除该差异。
5. 323 万可作为后续诊断与成本折中的候选网格，尚不能宣称已通过包含 461 万的 1% 联合网格无关性检验。要判断出口污染的因果影响，需要另做出口延长/回流温度敏感性对照；本次没有修改原案例、没有进行该对照重算。

网格检查均无负体积/连接性错误。所列正交质量最小值属于固体，不能据此断言流体尾部的质量极值；本次未取得流体专属质量直方图。

网格文件保留了 smooth-transition 设置。设置层数不等于每一处实际形成的完整层数。GrowthRate、FirstLayerHeight 未显式保存在工作流参数中；全局 prism 默认值不能代替实际平滑过渡增长率。实际近壁单元中心距提供了可测量的对比。
保存的 Add Local Sizing 任务没有显式 BOI 子任务，无法证实独立翼型尾部 BOI 的位置与尺寸。不能仅凭总网格数判断尾部的局部解析率。
水物性 UDF 的源文件和 host/node DLL 在两次续算工作目录中 SHA256 均一致；设置中四个挂接函数一致。完整指纹见“一致性核对与UDF指纹.json”。
需要纠正任务背景：保存的两组案例均为热壁面常数热流，无启用的流体/固体体积源项，未发现非均匀热源挂接。如果研究目标是非均匀热源，这批结果并未验证目标热源模型。

461 万保留了 0.1–0.103 s 小步长历史；最终时刻相同，完整时间步历史并非完全相同。保存的 time_step_count=10/7 是最后一次续算批次长度，最大每步迭代均为 20。

以出口外法向 +x 定义回流，采用 face mass flux<0，回流面积逐面求和，质量流量取负通量绝对值之和。最小通量等效速度为 ṁ_face/(ρ_face A_face)。Fluent 的面速度与保守通量由于压力插值/通量修正可有差异，因此同时列出两种速度，没有把它们混用。
两组回流面温度均为实际设置的 305 K，证明该边界温度在这部分面上已经生效。相对入口 300 K 的回流显热分别约占 42.875 W 加热功率的 3.70% 和 2.16%；这不是“回流导致的净温升”或敏感性试验结果，回流本身循环了已加热流体，不能据此直接判定误差大小。
323 万入口/出口面积加权压力为 2347.286485/-1.033863 Pa；461 万为 2448.316008/-0.398096 Pa。压降差主要来自入口压力变化，不是出口面积加权静压变化的 0.636 Pa 能直接解释的。
日志末步分别报告 740 面（5.2%）和 1030 面（5.4%）；实际积分面积比例与警告的四舍五入值一致。续算区间警告范围为 5.0–5.2% 与 5.4–5.5%。
Fluent 会在实际回流时使用回流条件：[Ansys pressure-outlet 说明](https://ansyshelp.ansys.com/public/Views/Secured/corp/v242/en/flu_ug/flu_ug_bcs_sec_bound_cond.html)。警告本身并不提供结果污染程度。

## 3. 内部回流与出口连通回流

用流体单元 Ux<0 定义逆向区域，并基于原网格 interior--fluid 面的 c0/c1 邻接关系计算三维连通区域。与负通量出口面相邻的负 Ux 单元所属连通分量标记为“出口连通”；其余记为“内部独立”。该方法避免仅凭二维流线把内部回流当成出口回流。

尾部回流不只在 461 万中出现。它的负 Ux 总体积比 323 万略增，局部最大逆向速度更大；同时出口回流质量流量变小。这符合“更细局部网格改变分离/回流解析”的可能性，但仍是观察性证据，不能独立证明其为压降偏移的唯一原因。
最强内部逆流点：323 万为 (x,y,z)=(0.718,2.734,0.340) mm，Ux=-0.469680 m/s；461 万为 (1.420,3.080,0.370) mm，Ux=-0.543023 m/s。二者均在内部翼型附近，不在 x=3.500 mm 出口。精确坐标及出口极值见“逆向速度极值位置.csv”和“逆向速度位置_出口与内部区分.png”。
最大的出口连通负 Ux 区域主要靠近两侧壁面，轴向范围约 0.98–1.02 mm（323 万）与 1.09–1.14 mm（461 万）。这些 x 跨度包含翼型侧部和侧壁回流，不能冒充单个翼型尾后的恢复长度。
相同 z=1.50 mm 截面上，最后一排翼型尾缘约 x=3.344 mm，出口位于 3.500 mm，仅有约 0.156 mm（约 0.31 个翼型弦长）的尾后空间。两组的这些尾后诊断窗口内均有负 Ux 延伸到接近出口的单元，且对应出口横向带存在负质量通量，说明该区域未充分恢复。
每个最后一排翼型的尾后长度、逆向速度、负 Ux 体积、出口回流流量及局部体积平均温压见“最后一排翼型尾部诊断.csv”。尾缘位置由公共截面栅格提取，误差约一个像素（5.4 μm）；尾迹长度在当前出口处被截断，不能测出域外的真实完全恢复长度。

## 5. 323 万网格能否采用

目前可以作为候选网格或暂时用于诊断，不能直接作为已经完成 1% 联合无关性验证的最终网格。294 万与 323 万附近存在局部平台；323 万对 461 万的 Nu、h、压降、表观 Darcy 因子仍超过 1%。Re/Pr 的小误差不足以替代传热与流阻验证。
优先按同一几何、表面网格、边界层层数/增长方式、BOI 范围和算法生成一组只改变尺度的网格；避免把不同生成策略混在一条收敛曲线上。
出口敏感性对照应保留原研究区与加热区域，将下游流体段延长，并在原出口截面取相同压差定义，避免把新增直段摩擦误认为原结构压降变化。实际充分恢复距离需由延长后结果确定。
回流温度对照应从相同初始结果、相同物理时刻和时间步历史开始，对合理的回流温度范围做成对试验，保持原入口/热源/UDF不变，并比较 Nu、压降、温度及回流流量。只有其变化与当前 1.56%/4.10% 的偏移相当，才能支持出口温度为主要成因。
若延长出口与统一网格策略后的 323 万/相邻更细网格均满足 1%，可采用 323 万；否则继续局部加密与时间步检验。不要以调高/调低回流温度使曲线靠拢作为网格无关性的依据。

## 文件与复现

原始案例保持不动。`audit_extract.py` 读取 HDF5 出口数据；`audit_fluent.py <grid>` 在独立 Fluent 会话只读导出单元体积/中心/场并检查质量；`audit_analyze.py` 通过温度及三个速度分量的精确匹配核对全局/分区排序，再计算体积统计和拓扑连通性；`audit_history.py` 检查时间变化；`audit_plots.py` 绘图。Fluent 2025 R1，双精度、8 进程。
所有最终原生数组均通过单元数、温度均值和出口通量与 HDF5 结果交叉核对。初次会话连续读第二个案例未成功切换，相关初次 461 万导出已用独立会话重做并验证；最终 461 万质量证据使用 `Fluent检查记录_4610769.trn`，不要使用第一次双案例会话中重复的 323 万质量段。
输出包括 PNG/PDF/SVG 图片、完整 JSON、CSV、原生数组与 Fluent 检查日志。
